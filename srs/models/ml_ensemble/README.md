# ML ensemble model artifacts

This directory stores the **trained parameters** for `XgbSvmEnsembleSimilarity`.

Do not hand-edit the files below. They are generated by:

```powershell
python manage.py train_ml_ensemble --input "path/to/OSNACA-Data-1.xlsx" --sheet "Data 24 clip"
```

After training, this folder should contain:

- `xgb_model.json` — trained XGBoost estimator
- `svm_pipeline.joblib` — fitted StandardScaler + RBF-SVM pipeline
- `manifest.json` — model version, selected soft-voting weights, evaluation metrics and preprocessing provenance
- `cv_fold_results.csv` — fold-level model-selection evidence
- `cv_summary.csv` — grouped cross-validation summary

The API only **loads** these files. It does not retrain during Django/Azure startup or during an analysis request.
