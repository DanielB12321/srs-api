# ML ensemble model artifacts

This directory stores the trained files used by `XgbSvmEnsembleSimilarity`.

Do not hand-edit the files below. They are generated by:

```powershell
python manage.py train_ml_ensemble --input "path/to/OSNACA-Data-1.xlsx" --sheet "Data 24 clip"
```

After training, this folder should contain:

- `xgb_model.json` - trained XGBoost estimator
- `svm_pipeline.joblib` - fitted StandardScaler and RBF-SVM pipeline
- `manifest.json` - model version, weights, metrics and preprocessing settings
- `cv_fold_results.csv` - results for each cross-validation fold
- `cv_summary.csv` - grouped cross-validation summary

The API only loads these files. Training is run separately with the command above.
